# Palatka AI v2.2.4 — Перепродажа + авто-пиар

**Статус:** собранный кандидат для Android MonetLoader; без нативной проверки этого обновления. Market Helper остаётся отдельным справочным проектом, в Palatka AI НЕ требуется для работы.

## Что нового

1. **Перепродажа → Сделки.** Рейтинг направлений «купить у лавки → продать скупщику» по готовым предложениям текущего рынка. Цена, проверенный/непроверенный остаток, риск, выручка, комиссия, чистая выручка, прибыль, ROI и крупные действия «Разобрать» / «Маршрут». Не совершает сделки. Опирается на существующий консервативный распределитель арбитража.
2. **Капитал и диверсификация.** Резерв 0/10/20/30%, ограничение на один предмет, минимум ROI, допустимый риск и сортировка. Общий капитал распределяется по сделкам только один раз; ограничение на один предмет предотвращает вложение всех денег в одну позицию. При капитале 0 расчёт условно без лимита.
3. **Риск и ликвидность.** Различает подтверждённое в игре количество и данные API; `qty=1` без подтверждения выделяет как особо рискованное. Количество скупщиков показывается как **индикатор интереса**, а не доказательство скорости продаж. Закрытие настоящей сделки остаётся решением игрока.
4. **Охота за ценами.** До 30 наблюдаемых предметов с целевой ценой и привязкой к серверу. Уведомления только по обновлённым уже полученным рыночным снимкам, не чаще одного в пять минут. По умолчанию отключены; не покупает товары. Для использования откройте детали подходящей сделки и выберите «Следить за ценой».
5. **Рекомендации цены.** «Быстро», «Рынок», «Маржа» на основе квартилей объявлений, с возможностью включить известную себестоимость для расчёта нижней границы без убытка. В отдельном окне можно сравнить API, данные маркера ЦР, подтверждённую историю продаж за сегодня и наблюдение открытой лавки. При наличии соответствующего товара выбранную цену можно применить к **активному пресету продажи**, а не к миру напрямую. Незнакомая себестоимость не считается нулём.
6. **Итоги заработка.** Денежные поступления, платежи, изменение наличных из подтверждённых трейдов в сохранённой истории. Сумма денежных потоков **не называется чистой прибылью**, поскольку вложения в предметы/их себестоимость могут быть неизвестны. Полный исторический журнал доступен прежней вкладкой.
7. **Авто-пиар.** Собственная библиотека до 8 именованных рекламных шаблонов `/vr`, `/s`, `/ad`, редактирование интервала 180–3600 секунд, включение нужного шаблона, ручная отправка, кнопки «Запустить» и «Остановить», предохранитель 12 сообщений за сессию. По умолчанию **не запущен**, пользователь должен включить его в каждой сессии, разрыв игрового соединения останавливает запуск. Непонятные окна `/ad` не подтверждаются автоматически. Ограничения сервера могут быть строже указанных; пользователь несёт ответственность за соблюдение игровых правил.

## Что не изменилось

- Название проекта, настройки, существующие пресеты и путь журналов.
- Автономный файл CP1251, исходный встроенный каталог, 8028 точных предметных PNG и безопасное обращение с ARM64 GPU texture pointer.
- Старые торговые очереди, журнал, расчёт арбитража, скан, метка лавки. Никакой зависимости от Market Helper.
- Включённый по умолчанию ТЕСТ-режим выставления. Новые возможности **не разрешают автоматических покупок или продаж**.
