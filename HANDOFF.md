## Запрос человека

Довести мобильный торговый инструмент Arizona RP для Android MonetLoader/mimgui: современный компактный тёмный UI по `docs/design/REFERENCE_UI.html`, большие фиксированные ▲/▼ и свайп, продажа/скупка с пресетами, лавки, корректный арбитраж, изучаемый журнал добычи/денег, мини-журнал, калькулятор. Не отключать старый функционал и не выдавать mock-тесты за телефон.

Последние конкретные просьбы:

1. Настоящие изображения предметов вместо одинаковой картинки коробки.
2. Итоги продажи: выручка, комиссия, чистая сумма и прибыль; бюджет скупки.
3. Включаемая/выключаемая 3D-метка отмеченной лавки, чтобы найти именно её.
4. Автоматический скан фактически открытой лавки, продажи и скупки; коррекция цен; перенос выбранных позиций в собственный существующий/новый именованный пресет; создание/переименование/удаление пресетов.

## Уже сделано и проверено автоматически

- UI 60–67 — единый активный слой. `DSP.ui21 == DSP.ui22` — намеренная совместимость.
- Реальные картинки: **8022 каталожных PNG + 6 точных названий вне старого каталога = 8028**. Источник/имя/SHA — `data/item_icons.json`. Изображения Arizona Games, не AI-иллюстрации. Нет случайного подбора по похожему названию; неизвестное изображение — `?`. 179 запросов дали 404, неоднозначные canonical-имена исключены. Шесть дополнительных изображений — Jester, портфель, четыре запечатанных предмета Devil Company.
- `08_icons.lua` читает PNG из хвостового блока самого Lua по byte offset/length. `build.py` формирует индекс и long comment с base64. В Lua heap не удерживается вся таблица картинок, сеть во время игры не нужна. GPU LRU — 96 текстур, не более одного нового декодирования за кадр. **Нельзя редактировать/перекодировать сгенерированный Lua вручную: сломаются смещения.** Исходники редактировать в UTF-8 и пересобирать.
- `37_trade_v16.lua` / `61_ui21_trade.lua`: фиксированные итоги обеих сторон; выключенные позиции не учитываются, неверный видимый ввод и переполнение не дают ложной суммы. `cost_price=nil` — неизвестно, `0` — явно бесплатно. Себестоимость задаётся в существующих подробностях предмета, сохраняется при импорте/экспорте (`21`). Комиссия/чистая сумма/прибыль обозначены `~`: округление может зависеть от разбиения по стекам. Скупка показывает сумму настроенных включённых строк.
- `45_live.lua`: слоты продажи/скупки раздельны, повтор пакета не увеличивает остаток. Legacy `amount` лавки — цена, не количество. Неизвестное количество остаётся nil.
- `46_shop_scan.lua`: снимок открытой лавки, наблюдаемые цены, перенос выбранных строк в именованные пресеты и явное обновление цен существующих позиций. Транзакция/откат при ошибке записи, guards server/revision/generation. Закрытый снимок можно изучать и переносить; доступность на сервере этим не гарантируется. Неизвестное количество при копировании становится пользовательским лимитом 1, а не доказанным остатком. Копия в продажу выключена до своей проверки инвентаря. Совпадения item+ench не должны повторно суммироваться.
- `62` / `67`: API/Скан лавки, наблюдаемые строки с выбором, модальное подтверждение переноса в существующий/новый пресет, отдельное обновление цен, переход к CRUD пресетов, кнопка 3D. Геометрия и операции проверены на четырёх размерах окна.
- `47_shop_marker.lua`: переключатель `marker_3d_enabled`, координаты серверного checkpoint после /findilavka и точных 3D-подписей лавок; цепочка предыдущих RPC-обработчиков сохранена. Текст рисуется в ImGui foreground с привязкой к мировой координате. Никаких координат игрока в качестве подделки цели. Смена сервера очищает цель. Модуль включён в build и install 99.
- Журнал/арбитраж/калькулятор и прежний функционал сохраняются. PayDay учитывает отдельный явный прирост депозита без повторного учёта банка; сырые JSONL не переписываются.

## Что действительно наблюдалось на телефоне

Galaxy A15, 2340×1080, MonetLoader 3.8.0-os, mimgui 2.0.1, LuaJIT 2.1.1713087254.

- Версия с 8022 картинками и итогами торговли была установлена. Реальные разные изображения ларцов/рулеток появились в журнале и пресете; продажа показала выручку $145040, комиссию примерно $1451 и чистую сумму примерно $143589. - **Шесть дополнительных именованных картинок, новый скан 45/46/67 и новая 3D-метка 47 добавлены ПОСЛЕ этой съёмки. Последний Lua не устанавливался на телефон. Для них есть тесты, но нативного PASS нет.**
- Ранее PNG-reload вызывал SIGSEGV. Причина доказана: mimgui округляет tagged ARM64 pointer через tonumber(uintptr_t). `36` сохраняет точный pointer и вызывает экспорт RwRasterDestroy через FFI; отключён небезопасный финализатор. После исправления три reload с PNG прошли. Не возвращать старый ReleaseTexture для tagged pointer и не лечить утечкой/отключением картинок.
- Ранее отдельно зарегистрирован Java APP CRASH/EXCEPTION без доступного traceback; причина не установлена. Не обещать отсутствие всех сбоев.
