# Palatka AI (Arizona Mobile Market Helper) — v1.5.0

Автономный, оптимизированный под сенсорные экраны помощник для торговли на Центральном Рынке Arizona RP (платформа **Android / MonetLoader x64 / MoonLoader**).

## 🚀 Основные возможности

- **Touch-first интерфейс**: Крупные кнопки под палец, адаптивный DPI под мобильные экраны (Samsung Galaxy A15 и др.), защита от обрезания длинных названий предметов.
- **Плавающая кнопка**: Быстрое открытие и скрытие меню в один тап по экрану.
- **Авто-открытие при занятии лавки**: Моментальное открытие меню пресетов выставления при взятии палатки.
- **Двухуровневый рынок (Dual-Source)**:
  - Облачный доступ ко всем лавкам сервера из любой точки карты (`va-ta.com` API).
  - Офлайн-сканер маркера средних цен на ЦР (диалог 15073).
- **Разделение скупки и продажи**: Расчёт с учётом реальных целых количеств продавцов и скупщиков, общим бюджетом и исключением повторного использования объёмов между связками.
- **Кнопка [📍 Отметить лавку]**: Установка GPS-метки и 3D-трейсера к выбранной лавке на ЦР.
- **Клонирование скупки**: Копирование чужой скупки в свой пресет в 1 клик с возможностью перебить цену на +1$.
- **Анти-скам радар**: Подсветка подозрительно завышенных цен и оверпрайса.
- **Логи дропов и Telegram-бот**: Учёт выпадения лута из ларцов/тайников, расчёт окупаемости и уведомления о сделках в Telegram.

## 🛠 Сборка

```bash
python3 build.py
```
Результат сборки сохраняется в `palatka_ai.lua` (CP1251).

## 📜 Команды в игре

- `/crr` — Открыть / закрыть главное меню.
- `/crlog` — Открыть / закрыть независимый мини-журнал.

Изменения текущей сборки: [RELEASE_1.3.3.md](RELEASE_1.3.3.md).

## Ограничения расчётов

- Арбитраж показывает **расчётный план** на основе последнего снимка рынка, а не реальные подтверждённые игровые транзакции; остатки могут измениться.
- План распределяет товар и бюджет без повторного учёта, используя жадный выбор по прибыли за единицу (при ограниченном бюджете — по рентабельности). Это **не гарантия математически оптимального** общего дохода.
- Слоты одного товара с одинаковой ценой в одной лавке объединяются, а слоты с разными ценами остаются отдельными.
- Версия не совершает покупку или сдачу автоматически: кнопки ведут к указанным лавкам.

## v1.4 — интерфейс и журнал

Открыть `/crr`, выбрать **Скупка / Продажа**, нажать **+ Добавить** и найти товар; цена и количество редактируются на одной панели. По умолчанию безопасная проверка без отправки. Изображения категорий уже встроены в `palatka_ai.lua` и распаковываются при первом запуске. `PalatkaAI/icons/items/<ID>.png` заменяет картинку категории. `/crlog` открывает журнал. Подробности и ограничения в RELEASE_1.4.0.md.
