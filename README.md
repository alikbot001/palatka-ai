# Palatka AI v2.1.0

Lua-скрипт торгового помощника для Android / MonetLoader x64 / MoonLoader. **Полная сборка с исходниками и визуальным эталоном интерфейса v2.1**.

## Установка

1. Поместить **`palatka_ai.lua`** в папку скриптов MonetLoader по правилам вашей установки.
2. Для изображений скопировать `icons/categories/*.png` в каталог рабочего состояния `PalatkaAI/icons/categories/`; точные изображения товаров размещать в `PalatkaAI/icons/items/<ID>.png`.
3. Открыть меню `/crr`, мини-журнал — `/crlog`.
4. Прежде чем запускать торговлю, просканировать инвентарь, вручную задать цены и проверить режим (`тест` / `реально`) в настройках.

## Сборка из исходников

`python3 build.py` — создаёт автономный `palatka_ai.lua` в кодировке CP1251 и делает синтаксическую проверку.

Локальные тесты новой версии: `texlua tests/test_ui21_pure.lua`, `texlua tests/test_ui21_render.lua`. Старые тесты в `tests/` требуют LuaJIT/FFI. Тесты **не** заменяют проверку в игре.

## Для следующих разработчиков и моделей

**Сначала прочесть `AGENTS.md`.** Дизайн-эталон: `docs/design/REFERENCE_UI.html`. Согласованные сценарии: `docs/design/ACCEPTED_REQUIREMENTS.md`. Контракт и ограничения: `docs/design/UI_CONTRACT.md`. Все четыре файла должны передаваться вместе с проектом, чтобы дальнейшие изменения не ломали принятые решения.

## Честные ограничения

Новая структура основана на согласованном HTML-прототипе, но пока не доказано пиксельное совпадение Lua UI на конкретном Android. Точные игровые изображения по каждому ID и полный парсинг всех видов наград требуют реальных данных. Реальные результаты торгов и своевременность API-предложений проверяются на сервере, а не по одному лишь отображению интерфейса.
