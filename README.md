# Palatka AI (Arizona Mobile Market Helper)

Автономный, оптимизированный под сенсорные экраны помощник для торговли на Центральном Рынке Arizona RP (платформа **Android / MonetLoader x64 / MoonLoader**).

## 🚀 Основные возможности

- **Touch-first интерфейс**: Крупные кнопки под палец, адаптивный DPI под мобильные экраны (Samsung Galaxy A15 и др.), защита от обрезания длинных названий предметов.
- **Плавающая кнопка**: Быстрое открытие и скрытие меню в один тап по экрану.
- **Авто-открытие при занятии лавки**: Моментальное открытие меню пресетов выставления при взятии палатки.
- **Двухуровневый рынок (Dual-Source)**:
  - Облачный доступ ко всем лавкам сервера из любой точки карты (`va-ta.com` API).
  - Офлайн-сканер маркера средних цен на ЦР (диалог 15073).
- **Разделение скупки и продажи**: Честная математика арбитража без путаницы между продавцами и скупщиками.
- **Кнопка [📍 Отметить лавку]**: Установка GPS-метки и 3D-трейсера к выбранной лавке на ЦР.
- **Клонирование скупки**: Копирование чужой скупки в свой пресет в 1 клик с возможностью перебить цену на +1$.
- **Анти-скам радар**: Подсветка подозрительно завышенных цен и оверпрайса.
- **Логи дропов и Telegram-бот**: Учёт выпадения лута из ларцов/тайников, расчёт окупаемости и уведомления о сделках в Telegram.

## 📁 Структура проекта

```text
├── src/
│   ├── 00_core.lua     # Ядро, утилиты кодировок, хранилище состояния
│   ├── 05_items.lua    # Каталог предметов Arizona RP
│   ├── 05_trades.lua   # Логирование сделок, парсер дропов ларцов
│   ├── 10_market.lua   # Рыночный модуль: Cloud API + Offline маркер
│   ├── 15_prices.lua   # Расчёт средних цен, анти-скам логика
│   ├── 20_presets.lua  # Пресеты скупки и продажи
│   ├── 30_ui.lua       # Сенсорный интерфейс mimgui
│   ├── 40_auto.lua     # Автоматическое выставление товаров в лавку
│   ├── 45_live.lua     # Хуки живых событий (трейды, диалоги, чат)
│   ├── 50_overlay.lua  # Оверлей и плавающая кнопка
│   └── 99_main.lua     # Точка входа скрипта
├── data/
│   └── arz_items.json  # Офлайн-база предметов Arizona RP
├── tests/              # Набор unit-тестов
├── build.py            # Сборщик скрипта в единый дистрибутив
└── PALATKA_AI_MASTER_PROMPT.md # Полное ТЗ и системный промт
```

## 🛠 Сборка

```bash
python3 build.py
```
Результат сборки сохраняется в `DsPic_Standalone.lua`.
