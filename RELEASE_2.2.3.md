# Palatka AI v2.2.3 — номер версии в интерфейсе

Palatka AI остаётся автономным проектом. RC4.1 — техническая метка внутренней ветки, не номер версии для игроков.

Изменена только нумерация: `DSP.version` и `script_version` теперь `2.2.3`; главный мобильный заголовок, экран настроек, чат-сообщение загрузки и legacy UI используют `DSP.version`. Игровые функции и PNG-банк не изменены.

Исторические проверки и нативные ограничения см. `docs/QA_RC4_1_INDEPENDENT_2026-10-27.md`. Переименование версии не подтверждает работу торговых действий на MonetLoader.
