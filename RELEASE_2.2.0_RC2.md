# Palatka AI v2.2.0 — RC2

Кандидат RC2: **51/51 автопроверок, exit code 0**. Нативная проверка новых предметных иконок и итогов торговли ещё ожидается; результаты устройства из RC1 остаются историей, а не доказательством этих изменений.

- Включены **8022 предметных PNG 96×96** из публичного сервиса изображений, используемого Market Helper. Каталог содержит 9069 ID; полное покрытие картинками не заявляется. Из первоначальных 8207 кандидатов исключены 179 ответов HTTP 404 и шесть неоднозначных ID после canonical trim/casefold.
- Manifest `data/item_icons.json` сохраняет имена, URL и SHA-256. Права на игровые изображения принадлежат Arizona Games/правообладателям; AI-замена не создавалась. Общие категорийные картинки больше не подставляются: неизвестное соответствие показывает `?`.
- Пользовательский `PalatkaAI/icons/items/<ID>.png` может переопределить встроенный ресурс. Встроенный банк находится в хвостовом long comment Lua и читается по байтовому offset/length только для нужного предмета. В игре нет HTTP-загрузки изображений и таблицы всех base64-payload в Lua heap.
- Кэш GPU ограничен 96 текстурами, новое декодирование — одно за кадр. Исправление точного ARM64 освобождения сохранено. Самостоятельный Lua стал значительно больше RC1; пиковая память и старт нового банка на телефоне ещё проверяются. Не изменять байты файла и не удалять его хвостовой банк.
- Итоги продажи/скупки закреплены под списком на вкладках «Предметы» и «Мой пресет». Скупка показывает точный бюджет настроенных включённых строк, без API-предположений.
- Продажа показывает выручку и приблизительные комиссию/чистую сумму/прибыль (`~`): разбиение на инвентарные стеки может менять округление. Это план, а не фактически полученные деньги.
- Себестоимость задаётся в подробностях предмета. `cost_price=0` — явно бесплатное получение; nil — неизвестно. Импорт и экспорт сохраняют различие. При неизвестной себестоимости прибыль не выдумывается; неверный видимый ввод и переполнение не показывают прежний итог как рассчитанный.

Подготовка ресурсов — необязательный настольный `tools/fetch_item_icons.py` с Python/Pillow. Новых зависимостей приложения/телефона нет.
