# Palatka AI v1.5.0 — облегчённый интерфейс

Сравнены приложенные дистрибутивы ArzMarket (ПК) и Market Helper (мобильная версия). Их код не переносился; логика торговли Palatka AI сохранена, UI переработан.

## Изменения

- Навигация: **Моя лавка / Арбитраж / Журнал / Поиск товара**. Остальные экраны — под **Ещё**.
- Переработан экран выставления скупки/продажи: два режима, текущий набор, кнопка добавления, редактирование цены и количества прямо в карточке, включение/выключение позиции, `+1` / `-1`, удаление, одно главное действие. Инвентарь, ручное добавление и управление наборами остались доступны без нагромождения на главном экране.
- Арбитраж **сгруппирован по предмету и заточке**. Если три лавки продают один предмет, будет одна сводная карточка, а все три лавки — внутри подробностей.
- В каждом предмете отдельно видны **общий объём продажи**, **общий объём скупки**, **объём реального плана** и **прибыль после комиссии**. Число из снимка больше не выдаётся за гарантированный остаток.
- В подробностях есть все продавцы и скупщики (цена за штуку, количество, ник, номер лавки, давность записи), отдельные прибыльные маршруты без двойного расходования запасов, флажки выбора и кнопки метки лавок.
- При расхождении с игрой нажмите **«Проверил в игре: исправить число»** возле скупщика: сохранится исходное число API, а введённый объём будет участвовать в расчёте до следующего обновления рынка.
- Интерфейс стал компактнее: без постоянной полосы прокрутки и без восьми постоянно открытых разделов.
- Сохранена поддержка PNG-предметов по ID; добавлен поиск ID предмета по имени в загруженном игровом каталоге. Без точных PNG показываются встроенные миниатюры категорий.
- В журнале прежние записи сделок и сырые сообщения чата доступны по отдельной кнопке, не смешиваются с основными событиями.
- Дополнительно: исправлен случай, когда постороннее сообщение чата ошибочно связывало награду с последующим тайником.

## Почему в старой версии было «скупает 1» вместо «700+»

Версия 1.4 могла показывать объём **одной выделенной связки**, а не сумму спроса по предмету. Если сам источник `buy_slots[].qty` содержит `1`, скрипт не может самостоятельно узнать о 700 шт. в игре: это устаревший либо неполный рыночный снимок. Теперь значения подписаны отдельно; ручное подтверждение в игре позволяет уточнить спрос, не выдавая предположение за факт.

## Установка

1. Поместите `palatka_ai.lua` в папку скриптов MoonLoader/MonetLoader и перезагрузите скрипты.
2. В игре: `/crr` — основное окно; `/crlog` — мини-журнал.
3. Для поиска локальных PNG по имени предмета скопируйте `data/arz_items.json` в `PalatkaAI/arz_items.json` рядом с сохраняемыми данными скрипта.
4. При наличии реальных изображений поместите `<id>.png` в `PalatkaAI/icons/items/`. Скрипт загружает их по ID, а без них использует изображения категорий.
5. Чтобы фактически выставить товары, отключите видимый флажок «Проверить без выставления (тест)» на экране торговли.

## Проверки

- `python3 build.py`: сборка CP1251 и проверка Lua-синтаксиса.
- 19 тестов `tests/test_*.lua` проходят в доступном тестовом окружении.
- **Не запускалось в реальном клиенте Arizona RP / MonetLoader**, поэтому отображение, доступность API и точность рыночных остатков требуют проверки в игре.

## Ограничения

- Снимок удалённого рынка не равен гарантированному остатку прямо сейчас. Игрок может изменить цену или объём, деньги скупщика могут закончиться. После обновления рынка ручные уточнения стираются.
- Расчёт выделяет объём между несколькими маршрутами, но сам не покупает товары из чужих лавок. Выбор галочками — маршрутный чеклист.
- Встроенные картинки по категориям — не официальные изображения каждого предмета.
