# Контракт пользовательского интерфейса Palatka AI v2.1

## Общие правила

- Один экран контента за раз; меню по кнопке, в свернутом виде не занимает места.
- Обязательные разделы: Торговля, Лавки, Арбитраж, Поиск, Калькулятор, История, Статистика, Заметки, Настройки.
- Тёмная компактная тема и небольшой синий акцент. Не использовать длинные абзацы, гигантские карточки или многоуровневые панели выбора.
- Листать пальцем по всему свободному пространству списка и через большие `^` / `v`. Нижняя панель действий всегда видна. Прокрутка не зависит от узкой стрелки scrollbar.
- `REFERENCE_UI.html` — **эталон интерфейса**. Он содержит демонстрационные данные и не является исполняемым торговым ботом. Реальные данные — исключительно от Lua-модулей.
- Формат Lua-скрипта CP1251: не добавлять символы, не представимые этой кодировкой, напрямую в исходники.

## Торговля

1. Выбор «Продажа / Скупка». Затем ровно две верхние вкладки: «Предметы» и «Мой пресет».
2. «Предметы»: инвентарь или каталог, текстовый поиск, один тап = добавить предмет. Для продажи из инвентаря количество = весь известный остаток. Цена из рыночной базы не проставляется.
3. «Мой пресет»: каждая строка = иконка + название + поле цены + поле количества + удаление. Нет отдельной страницы каждого товара.
4. Скупка: количество вручную + 1/10/100/Макс. «Макс» = явно введённый лимит, не придуманное значение API.
5. Наборы: выбор / создать / переименовать / экспорт / импорт Market Helper / удалить с модальным подтверждением.
6. Кнопка «Выставить» — выбор быстрого запуска или предварительного просмотра; запуск контролируется существующим движком и его валидацией.
7. После добавления остаёмся во вкладке «Предметы», чтобы выбрать несколько товаров подряд.

## Лавки

1. Сверху `Продают | Скупают` и **одна** строка поиска по предмету, нику и номеру лавки.
2. Одна строка = один точный товар с учётом заточки/модификации, лучший ценник, число лавок и общий объём в снимке API.
3. По нажатию новый экран подробностей — предложения каждой лавки (цена за штуку, количество, ник, номер), метка на карте; затем возможность посмотреть всё содержимое лавки.
4. Объёмы никогда не подменяются вычисленным торговым планом. При смене сервера/обновлении рынка недействительные подробности сбрасываются.
5. Показ времени/возраста снимка обязателен. Ошибка запроса не должна молча подменять другой сервер.

## Арбитраж

1. Одна компактная строка на предмет: имя, рассчитанное количество, ориентир прибыли.
2. Нажатие открывает новый экран: `Продают | Скупают`, показываются полные списки обеих сторон.
3. Можно выбрать конкретного продавца и конкретного скупщика и получить расчёт **этой пары**; отдельно доступны лучший распределённый план и выбор готовых маршрутов галочками.
4. Считать `cost / revenue after commission / profit / extra expenses`, допрасходы выключаемы.
5. Маршрут отдельным экраном: где купить, сколько, где продать, метки лавок.
6. Пример: 3 продавца x1, один скупщик x700 -> сырой запас 3, сырой спрос 700, план не больше 3. Прибыль пары и прибыль агрегированного плана не складывать друг с другом.

## Мини-журнал, награды и деньги

- Команда `/crlog` открывает маленькое плавающее окно; в меню также есть плотная история с фильтрами и детализацией события.
- Неизвестный тип события пишется как неизвестный с оригинальным текстом, не классифицируется автоматически как «Тайник Vice City».
- PayDay должен существовать как самостоятельная запись, данные детализации лишь если реально распознаны.
- Отображение и запись логов — разные настройки; Telegram не определяет запись событий.
- Пока нет эталонных логов всех типов кейсов, тайников и доходов, 100% точность распознавания **не подтверждена**.

## Производительность

- Группировка лавок по версии рынка и поисковому запросу кешируется; результаты не пересчитываются 60 раз в секунду.
- Арбитраж использует кешированный распределитель существующего движка.
- Долгие списки рендерить порциями. Не сохранять настройки на каждый кадр и каждое касание.
- Обновление данных фоновое, выполняется движком; экран никогда не блокирует игру сетевым вызовом.

## Отклонения Lua от HTML-эталона на момент v2.1.0

- HTML — макет с web CSS-типографикой и анимациями. В mimgui доступна схожая компактная структура, но не пиксельная копия CSS.
- Не проверены реальные DPI, касания, чувствительность свайпа и частота кадров на Android.
- Категорийные иконки есть, полнота точных изображений по ID зависит от установленного набора PNG.
- Часть старых вспомогательных экранов (статистика, настройки, заметки, поиск) сохранена из ядра без полной визуальной переработки.
