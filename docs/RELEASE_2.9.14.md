# Palatka AI 2.9.14 — 2 ноября 2026

Релиз исправления совместимости торговых диалогов после хэллоуинского обновления Arizona RP Mobile II.

- При выставлении товара скрипт связывает открывшееся окно ввода цены с последним кликом по слоту. Новые ID разрешены только для свежих соответствующих диалогов ввода; прежние ID продолжают работать.
- В журнале фиксируются ID, тип и заголовок новых торговых окон без сохранения введённых в них значений.
- Неполные JSON-структуры буферизуются отдельно по интерфейсу и подпакету, с TTL 3,5 секунды и ограничением 1 МиБ. Независимые пакеты не склеиваются.
- Сохраняются пресеты и существующая проверка остатка товара при продаже.
- Обновлены автономный `palatka_ai.lua`, версия в сборщике и отдельный OTA для пользователей 2.9.13.

Тесты на LuaJIT покрывают распознавание новых диалогов, изоляцию фрагментов JSON и разрыв на отметке 8192 байта. Нативная игровая проверка нового протокола не выполнена; конкретный новый `interfaceid` и структура серверного JSON пока не подтверждены дампом. Это ограничение диагностики, а не пометка выпуска Beta.

Если в приложении написано `Network is unreachable`, это отдельная ошибка подключения HTTP из MonetLoader: наличие нового релиза на GitHub само по себе не устраняет сетевые проблемы устройства. Для ручного обновления использовать `palatka_ai.lua` из `main`.
