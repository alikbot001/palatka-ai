# Palatka AI 2.9.17 — компактный интерфейс и обновления
Дата: 8 ноября 2026.

## Изменения
- Главное меню уменьшено до семи пунктов: Торговля, Лавки, Арбитраж, Автопиар, Хранилища, Журнал, Настройки.
- Остальные экраны НЕ удалены: включи «Настройки → Интерфейс → Полное меню» для доступа ко всем прежним пунктам.
- Главная страница оставляет только основные действия, версию и статус рынка.
- Настройки по категориям: Основные, Интерфейс, Торговля, Сканирование, Рынок, Обновления, Расширенные. Старый экран параметров (включая Telegram и внешний вид) сохранён в «Расширенные».
- «Обновить цены рынка» обновляет только рынок. «Обновления → Проверить GitHub» сравнивает версии скрипта. Установка требует отдельного подтверждения.
- OTA загружается только из GitHub репозитория проекта по HTTPS; перед применением сверяются версия, URL, размер и синтаксис Lua. Скачанная копия сохраняется в папке Palatka AI.
- Когда идёт продажа или скупка, установка обновления блокируется.
- Пресеты, настройки, журналы и старая торговая логика не сбрасываются.

## Сборка и проверка
- Чистая установка: `python3 build.py` собирает автономный `palatka_ai.lua` из исходников.
- OTA: `python3 tools/build_ota_v2917.py` собирает `updates/palatka_update.lua` и `version.json`.
- Тест интерфейса: `luajit tests/test_v2917_ui.lua`.
- CI собирает 2.9.17 и повторяет регрессии 2.9.16, включая выставление продажи и стабильность окон.

## Ограничения
- Автотесты не заменяют испытания Android/MonetLoader в игре. Сначала проверь отображение, сохранение настроек, переходы по страницам и обновление в безопасной сессии.
- Загрузка Lua зависит от того, как установленная библиотека `requests` возвращает байты; при несовпадении размера установка откажет, чтобы не запускать повреждённый файл.
- Не публиковать поверх main без успешного CI и ручной проверки.
