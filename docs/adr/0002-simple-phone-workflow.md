# Простое управление на телефоне

Status: implemented in 1.3.1; local tests passed; new phone layout awaits observation.

## Context

Пользователь проверил первую сборку на телефоне и сообщил о сложности выставления,
неподвижном окне, неудобной прокрутке, неработающем закреплении мини-журнала и
неочевидных карточках арбитража. Первую вёрстку нельзя считать принятой.

## Decision

Основной сценарий: скупка/продажа, выбранный набор, цены и количество, одна кнопка
выставления. Импорт, редактор наборов и остальные инструменты находятся в
«Дополнительно». Импорт сразу выбирает импортированный набор.

У главного окна есть отдельная ручка перемещения и сохраняемая позиция.
Относительная прокрутка управляется крупными кнопками у края с тремя вариантами
шага. Карточка арбитража показывает обе стороны сделки и расчёт партии после
комиссии. Мини-журнал переписан отдельно: один якорь положения для двух размеров,
PIN открывает журнал и блокирует перемещение; основное окно им не управляет.

## Consequences

Проверка основного действия остаётся явной: «Выставить» выполняет выставление,
«Проверить» из дополнительных настроек выполняет пробный проход. Закрепление
должно одинаково действовать из самого журнала и из настроек. До проверки на
телефоне нельзя утверждать, что новая вёрстка визуально принята пользователем.
