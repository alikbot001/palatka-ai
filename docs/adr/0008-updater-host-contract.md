# Ошибка контракта установщика local.5

Status: fixed in local.6; native retest pending.

## Context

Пользователь получил «Некорректное описание обновления». Проверка агентом
на опубликованном JSON установила: local_update_host.lua не передавал decode,
а updater.lua вызывал pcall(h.decode,raw). Сетевой ответ был корректен. Тест
установщика создавал собственный host с декодером и пропускал эту интеграцию.

## Decision

Передать T.decode в настоящий host; проверить наличие функции при создании
установщика. Добавить тест с исполнением настоящего host-адаптера. Увеличить
номер выпуска: исправление старого установщика сначала ставится через ADB.
Отдельно воспроизведены и исправлены merge-only полный refresh, потеря явной
метаинформации вложенных предметов и отсутствие повторной записи отметки
уведомления после временной ошибки диска. Не угадывать смысл opaque unic_id.

## Consequences

Прошлый unit-набор не является доказательством правильной wiring-интеграции.
Новый набор проверяет реальный host и уведомление. Сетевые ошибки и плохой
JSON отличны от отсутствующего обязательного обработчика. В текущем источнике
не выдумываются отсутствующие лавки, ID или вложенные улучшения. Принятие на
Android требует повторения пользовательской команды в исправленной версии.
