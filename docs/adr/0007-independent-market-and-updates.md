# Независимые рыночные данные и обновление локальной версии

Status: implemented; Android acceptance pending.

## Context

Пользователь подтвердил: без MCR-ключа пропадают лавки и средние цены.
Ранее transport fence только запрещал MCR HTTP; родные виды оставались
без источника. Пользователь предоставил https://va-ta.com/app/#shops и
попросил /crrupdate и уведомления по образцу Market Helper.

## Decision

Использовать наблюдённый публичный JSON Market Helper для текущего мобильного
сервера. Собственный read model из канонических снимков обслуживает родные
разделы MCR без его HTTP/ключа. Не копировать код или Premium-функции Market
Helper; установленный сторонний скрипт не нужен. Сохранять источник и время,
разделять серверы/валюты/модификации. ID=0 — только чтение, не арбитраж.
Лимит строк снимка поднят 256→512: в реальном ответе встречены 296 строк;
лимиты 128 лавок и 20000 сравнений остаются. Средние — взвешенные цены
объявлений, не доказанные сделки. Старые и будущие снимки исключаются.

Обновление получает только два фиксированных URL собственного GitHub-канала
mcr-local. Проверки в фоне уведомляют, команда устанавливает. Собственный
SHA256 использует встроенный LuaJIT bit, новые зависимости не нужны. Перед
атомарной заменой проверяются размер/хэш/синтаксис и сохраняется старый Lua.
Установщик не касается JSON настроек и отказывает при активной операции.
Stable/main и их каналы не меняются. Установка не вызывает автоматическую
перезагрузку игрового обработчика; после неё пользователь перезапускает игру.

## Consequences and evidence

Публичные ответы трёх Mobile-серверов получены без ключей; 64/69/47 снимков
приняты адаптером. API Arizona Market не включён: опубликованы PC-серверы,
доступность живого endpoint в этой среде не подтверждена. Доступ к сторонней
базе не гарантирован навсегда; свежий кэш и свои сканы переживают сетевые ошибки.
Закрытая MCR-история/личные облачные данные не подделываются и не переносятся.
Тесты исполняют родные data-adapter callbacks при пустом ключе, проверяют
ошибки сети/смену сервера/хэш/URL/занятость/резервную копию и отказ rename.
Нативная Android-проверка требует подключённого телефона.
