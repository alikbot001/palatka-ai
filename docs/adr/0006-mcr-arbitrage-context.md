# Контекст действий в арбитраже MCR

Status: implemented; native UI acceptance pending.

## Context

Пользователь сообщил о технических именах источников/серверов, неясном
товаре у кнопок продавца/скупки и расположении новых окон сверху.

## Decision

Сохранить оригинальные панели и модальные окна MCR. Разделить список
и карточку конкретного маршрута в центральной панели. Выбор только явный;
переход к лавке проверяет актуальность результата и текущий сервер.
Идентификаторы предмета и модификации остаются видимыми для различения
одноимённых товаров. Остаток предложения, спрос и план — отдельные величины.

Подпись сервера не участвует в ключах кэша. Вместо названий адаптеров
показываются понятные источники. Кэш и импорт объединены в «Источники цен»
с объяснением отсутствия сетевого обновления. Новые окна позиционируются
по текущему DisplaySize с Cond.Appearing и центральным pivot.

## Consequences

Нет автоматических сделок, новых зависимостей и изменений формата базы.
Вычисление и запись остаются вне кадров UI. Инвалидация снимает выбор.
Тесты исполняют выбор/поиск сторон маршрута, запрет старых действий после
смены сервера, разницу объёма плана и снимков, подписи, центр модальных
окон и геометрию правой панели. Реальные касания требуют отдельной приёмки.
