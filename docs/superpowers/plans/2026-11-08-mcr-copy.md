# MCR Copy Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Полный клиент MCR Mobile с отдельным локальным разделом арбитража.
**Architecture:** Immutable vendor source + reproducible narrow integration patches;
pure arbitrage engine, source adapters and UI sharing the existing mimgui panels.
**Tech Stack:** LuaJIT, MonetLoader, mimgui, Python standard library.
**Spec:** docs/superpowers/specs/2026-11-08-mcr-copy-design.md

## Global Constraints

- Preserve original client behavior, attribution and authentication; no fake responses.
- CP1251 output, no new installed dependencies, no edits to main's generated Lua.
- Local scans segregated by server, stale/unknown quantities never executable routes.
- No money-moving calls in new arbitrage module, no HTTP or disk writes in rendering.

## Review Focus

- Same shop imported from multiple sources must not double its stock (task 1).
- Missing enhancement/quantity/time must not become a guessed actionable route (task 1).
- Switching server or cancelling a calculation cannot show previous routes (task 2).
- Every original frame and function must survive source assembly (task 3).
- Failure saving local data must remain visible without deleting old data (task 2).
