# Минутное обновление рынка

Требование: обновлять общий рынок для арбитража раз в минуту, после загрузки
пересчитывать активный арбитраж. Игру и телефон не использовать.

- [x] Воспроизвести двухминутную задержку тестами настоящего host coroutine
  и приложения с виртуальным временем: прежние таймер/кэш дают RED.
- [x] Изменить host wait на 60000 мс, кэш app на 60 секунд; сохранить один
  запрос на сервер, явное принудительное обновление и проверку владельца.
- [x] Фоновый poll принудительно обновляет базу: задержка ответа не должна
  превращать минутный цикл в двухминутный. Добавить ответ через секунду
  после запроса и проверить следующий запрос ровно на следующем тике.
- [x] Проверить границы 59/60 секунд, повторный poll во время загрузки и
  исчезновение устаревшего варианта после ответа с новой ценой.
- [x] Общий verify, независимое ревью и standalone CP1251 build local.12.
- Опубликовать candidate в прежней ветке/PR и теге mcr-local.12;
  скачать опубликованный файл и проверить SHA256.

Сокращается период запроса базы, а не возраст исходного скана. Публичный
источник может отдавать прежние данные. Принудительное обновление также
обновляет доступную статистику продаж; незавершённые запросы объединяются.
Запросы не добавляются в отрисовку интерфейса.

Проверка: 27 Lua-наборов и 14 Python-тестов — exit 0. Независимое ревью
подтвердило запрос на следующем минутном тике при задержке ответа и отсутствие
повторного запроса до завершения первого. Артефакт: 2 160 116 байт,
SHA256 `16eb0ffc1bc8b1625d885b8bb1e03910ae7d8ccac89f910827a264e03ca9b1b0`.
Нативная проверка не выполнялась.
