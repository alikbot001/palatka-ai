# Полная копия MCR Mobile + арбитраж

Основание: прямое требование пользователя — полная копия MCR Mobile по стилю,
окнам и функциям; единственное новое дополнение сейчас — раздел арбитража.
Предыдущий вариант лишь перекрасить Palatka отклонён.

Выбранный подход: сохранить полный извлечённый клиент MCR 1.15.5 как основу
отдельной экспериментальной сборки, добавить модуль арбитража в его существующие
левую, центральную и правую панели. Не переносить остальные экраны Palatka.
Альтернативы: UI-only PR25 не выполняет запрос; переписывание всех функций вручную
увеличивает риск расхождения с оригиналом.

Арбитраж получает снимки реально открытых лавок, просмотренные внешние предложения
MCR и явный импорт нормализованных внешних снимков. Хранение локальное, отдельно
от настроек MCR. Сервер, источник, возраст, идентичность предмета и количество
обязательны. Не считать объявления завершёнными сделками, не торговать автоматически.
Недоступный чужой API не заменять выдуманными данными. При отсутствии данных — пустое
состояние с объяснением. Повторно один и тот же объём не выделять.

Полная копия сохраняет исходную авторизацию и облачные функции MCR: извлечение
клиента не воспроизводит сервер, не выдаёт бессрочный ключ. Новый локальный модуль
сам не требует ключа MCR. Не подменять ответы сервера. Это ограничение копирования
оригинала, а не обещанная готовая независимая замена его серверной части.

Исходная main и штатный build.py остаются отдельными от экспериментального билда.
Нужны тесты расчёта и интеграции, CP1251-сборка, синтаксис, startup smoke и отдельное
указание нативной приёмки. Публикация Stable и изменение телефона сюда не входят.
