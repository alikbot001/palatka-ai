## 2. Почему текущие методы Palatka AI не работают

### Ошибка №1: Ожидание SA-MP Dialog (`src/47_storage.lua`)
В модуле `47_storage.lua` парсинг реализован так:
```lua
function S.on_dialog(id, style, title, text)
    local kind = kind_of(title)
    if not kind then return false end
    local ok, err = S.accept(kind, title, text)
    ...
```
- **Реальность:** При открытии багажника или шкафа в клиенте v17.3.8 сервер Arizona вообще **НЕ ОТПРАВЛЯЕТ RPC ShowDialog**!
- Движок открывает нативное Android-окно `ru.mrlargha.commonui.elements.inventory.presentation.InventoryScreen`.
- В результате функция `on_dialog` получает 0 вызовов, и сканер сообщает: «нет снимков».

### Ошибка №2: Ожидание TextDraw (`src/47a_storage_textdraw.lua`)
В версии v2.2.10 был добавлен экспериментальный сбор TextDraw (`arm_textdraw`):
```lua
function S.observe_textdraw(id, value)
    ...
```
- **Реальность:** Нативные контейнеры Arizona Mobile не отрисовываются через SA-MP TextDraw!
- Они отрисовываются через Android Views / Jetpack Compose поверх экрана игры.
- В итоге сбор TextDraw завершается с ошибкой: `В TextDraw не обнаружен заголовок хранилища. Возможно, окно нативное.` (что абсолютно точно зафиксировано в коде!).

## 3. Правильная стратегия надёжного сбора данных

Для гарантированного и пассивного сбора содержимого любого хранилища необходимо использовать **гибридный трёхуровневый сборщик**:

### Уровень 1: Сетевой перехватчик Packet 220 (Основной)
- Слушает `onReceivePacket` (packet_id == 220).
- Декодирует JSON-пакеты событий инвентаря и контейнеров (`event.inventory.*`, `containerContent.*`).
- Извлекает массив предметов:
  ```json
  [
    {"slot": 0, "id": 1050, "name": "Гражданский талон", "count": 450},
    {"slot": 1, "id": 1002, "name": "Бронежилет", "count": 5}
  ]
  ```
- Гарантирует 100% точность: точный ID предмета, точное название и точное число в пачке без эвристического парсинга текста!

### Уровень 2: Fallback на SA-MP Dialogs (Совместимость)
- Сохраняет перехват `sampev.onShowDialog`.
- Необходим, если игрок играет на старых серверах или сервер временно переводит игрока на классический диалоговый интерфейс.

### Уровень 3: Ручной ввод (Гарантированная резервная копия)
- Позволяет вставить текст списка предметов вручную построчно.
