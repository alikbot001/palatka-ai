# local.8: исправления аудита 10 ноября 2026

Проверенная исходная точка: local.7, `9a3cabd`. Кандидат: local.8/build 8.
План: [поэтапная работа](superpowers/plans/2026-11-10-local8-audit-fixes.md).

| Дефект | Исправление и проверка |
| --- | --- |
| Обновление продажи запускало каталог скупки | Восстановлено разделение sell/buy; проверены счётчики фактических вызовов извлечённой функции |
| Удалена вся страница Telegram | Восстановлены родные поля token/group и переключатели уведомлений; отключён только выбор MCR-бота |
| `Предмет(+4)` не находился | Единое имя и совместимость со старым пробелом; отдельная проверка вложенных улучшений |
| Одинаковые названия разных ID | ID/вариант видны в таблице; кнопки выбора внутри родного child; группы валют и модификаций остаются отдельными |
| Старый callback заменял новый экран | Поколения запросов для поиска, общей таблицы, карточки и Y6; обратный порядок ответов проверен на одном и разных серверах |
| Установка во время скупки | Реальный адаптер учитывает m6 и isParseInventoryDialogsForBuy до и после скачивания; оригинал и backup не меняются при блокировке |
| Тайм-аут HTTP зависел от CPU | CLOCK_MONOTONIC через существующий LuaJIT FFI; ожидание 120 мс при лимите 30 мс завершает запрос ровно один раз |
| Бесконечный поиск UID | Максимум 30 секунд/5 запросов на попытку; отсутствующий UID не выдаёт готовность ни на одном загрузчике; настоящий `/stats` распознаётся штатным парсером |

Регрессии сначала воспроизведены на старом поведении, затем проверены после
исправлений. Независимый просмотр дополнительно выявил конфликт общей FFI-декларации,
повторную инициализацию таймера и отсутствие UID-ограничения на MonetLoader.
Для них также выполнен цикл RED → GREEN. Выбор вариантов кэшируется и
вычисляется через host.run, чтобы не сортировать рынок каждый кадр.

`python3 mcr_copy/verify.py`: 12 Lua-наборов, 13 Python-тестов и сборка — exit 0.
Подробный вывод: [отчёт](../outputs/palatka_mcr_checks.json).
Готовый CP1251-файл проверен настоящими SHA256/LuaJIT compile и цепочкой
установщика с контрольным install-callback (файлы телефона не затрагивались).
Были выполнены 129 кооперативных уступок при проверке SHA.

Размер: **2 103 273 байт**. SHA256:
`a294d6e235dd1916d135f3bb7fd33fb2c83384e2a3062025be72302299f8784c`.
Значения синхронизированы с манифестом обновления сборщиком.

Нативная приёмка **не выполнена**: `adb devices -l` не видит телефон.
Последняя подтверждённая установка — local.6. Рендер, ABI таймера на Android,
команда обновления в игре и реальные серверные торговые ACK требуют отдельной
проверки. Реальные покупки/продажи не выполнялись. Старый набор другого
артефакта `palatka_ai.lua` не перезапускался; его известный прежний baseline
69/111 не считается результатом проверки local.8.

Ключ MCR не используется; закрытые история/облако/бот не имитируются.
Публичные снимки требуют интернета и могут отставать от игры. Изменения
относятся к кандидату `mcr-local`; main/stable не продвигаются.
