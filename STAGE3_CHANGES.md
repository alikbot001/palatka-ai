## Логгер 60 FPS без фризов

**Архитектура**:

```
┌──────────────────────────────────────────────────────┐
│  Сделка / Тайник / PayDay                            │
│              ↓                                       │
│  DSP.craglog.log_trade(entry)                        │
│              ↓                                       │
│  ┌────────────────────┐    ┌──────────────────────┐  │
│  │  Ring buffer OЗУ    │ +  │  Append-only file    │  │
│  │  300 entries        │    │  all_trades.log      │  │
│  │  O(1) push          │    │  handle stays open   │  │
│  │  O(n) recent        │    │  flush() per write   │  │
│  └────────────────────┘    └──────────────────────┘  │
│         ↓                            ↓                │
│  /crlog mini-window          Long-term log            │
│  (instant render,           (GB-scale, no RAM cost)   │
│   300 entries max)                                   │
└──────────────────────────────────────────────────────┘
```

**Ключевые свойства:**
- `logs/all_trades.log` может весить **гигабайты** — скрипт никогда его не читает, только дописывает. 0 фризов даже при огромных логах.
- В ОЗУ только 300 последних транзакций + счётчики. Ring buffer — это массив + head pointer, O(1) push без `table.remove` shifting.
- `file:flush()` после каждой записи — переживает game crash, последняя сделка сохранена.
- Mini-window читает ТОЛЬКО ring buffer, никаких disk reads в OnFrame.

## Mini-window `/crlog`

**Команда** `/crlog` — переключает видимость. Работает **независимо** от `/crr`
(главное окно может быть закрыто, мини-лог виден).

**Развёрнутый режим** (560·dpi × 420·dpi):
```
┌─────────────────────────────────────────────────────┐
│  craglog / мини-лог                            [X] │
│  Прибыль сессии: +14.5кк (42 сделок, 18 ларцов)    │
│─────────────────────────────────────────────────────│
│  [ Все ] [ Продажи ] [ Скупка ]  [ PIN ] [ - ]     │
│  [ Очистить ]                                       │
│─────────────────────────────────────────────────────│
│  23:45:12  PAYDAY: 38 сделок, прибыль +12.3кк      │
│  23:42:08  [Тайник Илона Маска] +1x Алмаз           │
│  23:38:55  [Тайник VC] +5x Дрова                    │
│  23:35:02  trade | Vanya_Pupkin | +1.2кк            │
│  ...                                                │
└─────────────────────────────────────────────────────┘
```

**Свёрнутый режим** (плашка 480·dpi × 36·dpi снизу-слева):
```
[ Прибыль: +14.5кк | Продаж: 6 | Скупок: 2 [+] ]
```

Кнопка `[+]` разворачивает обратно. Кнопка `[PIN]` фиксирует окно (запрет
свёртывания). Кнопка `[X]` закрывает. Кнопка `[Очистить]` сбрасывает ring
buffer + счётчики (файл на диске НЕ трогает).

**Фильтры**:
- `[Все]` — все записи (трейды + кейты + PayDay маркеры)
- `[Продажи]` — только трейды где `money_get > 0 AND money_give == 0`
- `[Скупка]` — только трейды где `money_give > 0 AND money_get == 0`

## Экран ЗАМЕТКИ

`InputTextMultiline` 8192 символов на всю доступную область. Header:
```
ЗАМЕТКИ   Автосохранение в config/PalatkaAI/notes.txt (debounce 1.5с)   OK
                                                            [ Сохранить ]
─────────────────────────────────────────────────────────────────────────
[Большой текстовый редактор на всё окно]
```

**Auto-save логика**:
1. Каждое нажатие клавиши → `DSP.ui._notes_dirty = true`, `_notes_last_edit = os.clock()`
2. В OnFrame (после `draw()`): если `dirty AND os.clock() - _notes_last_edit > 1.5` → write to `notes.txt`, `dirty = false`
3. При ручном тапе `[ Сохранить ]` — мгновенный write

Индикатор состояния: `OK` (зелёный) когда всё сохранено, `* не сохранено` (жёлтый) когда есть несохранённые правки.

## 6 паттернов парсинга тайников

В `DSP.logs.parse_chat_drop` (заменён полностью):

```lua
-- 1. "Вам выпало из {source}: {item} ({qty} шт.)"
{ '^Вам выпало из (.+): (.+) %((%d+) шт%.%)', 3 }
-- 2. "Вы открыли {source} и получили {item}"
{ '^Вы открыли (.+) и получили (.+)', 2 }
-- 3. "Вам выпало: {item} ({qty} шт.)"
{ '^Вам выпало: (.+) %((%d+) шт%.%)', 2 }
-- 4. "Вам выпал[оа]? {item}" (муж/жен/ср род)
{ '^Вам выпал[оа]? (.+)', 1 }
-- 5. "Вы использовали {source} и получили {item}"
{ '^Вы использовали (.+) и получили (.+)', 2 }
-- 6. "Вы успешно открыли {source} и вам выпало {item}"
{ '^Вы успешно открыли (.+) и вам выпало (.+)', 2 }
```

Каждое совпадение возвращает `{ name, ench, qty, source }` где `source` —
название источника («Тайник VC», «Тайник Илона Маска» и т.д.). Это позволяет
в будущем считать статистику по типам тайников (сколько открыто Тайников VC,
сколько выбито из Тайников Илона Маска).

**Интеграция**: `crate_opened(item, price, qty, source, ench)` теперь принимает
`source` и `ench` как параметры, а не игнорирует их. Telegram-уведомление о
дропе ларца теперь шлёт название источника: `[palatka ai] [+] Тайник VC: +5x Дрова`.

## Telegram PayDay

В `DSP.live.check_payday_message(text)`:

1. Чат-хук `sampev.onChatMessage` → `DSP.logs.log_chat(message)` → `DSP.live.check_payday_message(s)`
2. Если строка содержит один из 5 паттернов PayDay:
   - `'PayDay'`, `'ПэйДэй'`, `'ПейДей'`, `'вы получили зарплату'`, `'Вам начислена заработная плата'`
3. Throttle: если `os.time() - tg_payday_last < 1800` сек → пропустить (дубликаты)
4. Иначе: `DSP.logs.profit_summary('day')` → push в craglog → UTF-8 Telegram:
   ```
   [palatka ai] PayDay 23:00
   Сделок за день: 38
   Прибыль: +12.345.678$
   Получено: $45.000.000
   Отдано: $32.654.322
   ROI: 37.9%
   Средняя сделка: $324.623
   ```

Включается чекбоксом `[x] PayDay сводка (XX:00)` в Настройках → Telegram.

## Перетаскиваемая кнопка `[CR]`

Stage 1 давал статичную кнопку `[CR]`. Stage 3 добавляет drag handle:

```
┌──┬────────────────┐
│::│      [CR]       │   ←  18·dpi drag handle + 58·dpi open button
└──┴────────────────┘
```

- Левая полоса `::` (18·dpi ширина) — drag handle. Цвет: accent·0.30 (полупрозрачный).
- Правая кнопка `[CR]` (58·dpi) — открывает главное окно.
- Touch-friendly: тап-зона ≥ 36·dpi высоты, drag-strip достаточно широкий для пальца.

**Drag-логика**:
- `imgui.IsItemActive()` на drag handle → true пока пользователь держит палец
- `io.MouseDelta.x/y` → смещение курсора с прошлого кадра
- `DSP.settings.cr_pos = { x = clamp(px + mdx), y = clamp(py + mdy) }`
- Clamp в пределах экрана: `[4, sw - 76·dpi - 4] × [4, sh - 60·dpi - 4]`
- Persist: если `_cr_pos_dirty`, каждые 5 сек → `DSP.save_ui_state()` → `config/PalatkaAI/ui_state.json`

## Известные ограничения

- **3D-трейсер к лавке** (визуальный луч в мире игры к отмеченной лавке) НЕ
  реализован — это потребует доступа к `sampGet3dTextInfoById` + рендера линий
  в 3D, что в MonetLoader на A15 может быть нестабильно. Сейчас `[Отметить
  лавку]` только шлёт `/findilavka N` (GPS-маркер на карте), что достаточно
  для большинства кейсов.

- **Клавиатура на Android**: при вводе в `InputTextMultiline` системная
  клавиатура MonetLoader'а должна открываться автоматически. Если нет —
  проверь настройки MonetLoader → Управление → Активная клавиатура.

- **Длина заметок**: 8192 символов (8 КБ). Если нужно больше — измени
  `DSP.ui.notes_buf = imgui.new.char[8192]()` в `30_ui.lua` и пересобери.

- **craglog file handle**: остаётся открытым на весь lifetime скрипта. При
  выгрузке скрипта (game crash или `/lua unload`) Lua автоматически закроет
  handle через `__gc`. Если нужно вручную — добавь `imgui.OnExit()` хук.
