# Palatka AI 1.3.3 — Арбитраж и интерфейс

- **Запас и спрос:** несколько слотов одного товара по одной цене в одной лавке суммируются; слоты с разными ценами считаются отдельно.
- **Без двойного учёта:** товар продавца, ёмкость скупщика и общий бюджет не используются повторно в разных связках.
- **Точная партия:** отображаются исходные остатки продавца и скупщика, выделенное число штук, затраты, комиссия, чистая прибыль и ROI.
- **Серверы:** при смене сервера данные прошлого сервера скрываются; отсутствие кэша выбранного сервера больше не приводит к подмене кэшем Mobile II.
- **Дизайн:** обновлены экран арбитража, мобильные карточки, порядок полей, визуальное выделение прибыли, предупреждения о кэше, расширенные действия поиска лавок и сводка итогов.
- **Данные:** объёмы проверяются как неотрицательные целые; предложения с нулевым запасом не участвуют в расчёте.
- **Совместимость:** автономный `palatka_ai.lua` остаётся в CP1251 для MonetLoader/MoonLoader.

**Ограничение:** расчёты делаются по снимку API, а не непосредственно по запасам в игре. Распределение жадное, не гарантирует математически максимальную прибыль среди всех вариантов. Тесты логики и синтаксиса пройдены в Lua, но внешний вид не проверен внутри игры.

Установка: заменить предыдущий `palatka_ai.lua` в папке скриптов; исходники — в `src/`. Команды: `/crr`, `/crlog`.
