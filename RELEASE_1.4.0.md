# Palatka AI v1.4.0 — UI + журнал

## Изменения

- Новая стандартная тёмно-синяя тема `Palatka Blue`, миграция стандартной amber-темы 1.3.x (другие темы сохраняются).
- Один компактный редактор для продажи/скупки: выбор стороны, набор, иконка предмета, цена, количество, +/- и удаление на одной панели.
- Быстрый поиск предметов в рыночной базе, импорт из инвентаря, ручной ввод и наборы доступны по кнопке `+ Добавить`.
- Большая кнопка действия с безопасным режимом `Проверить без выставления`; отключение режима позволяет выставить позиции.
- 8 встроенных иллюстративных миниатюр категорий. Скрипт автоматически распаковывает их в `PalatkaAI/icons/categories/`.
- Для точной игровой картинки предмета поместите PNG в `PalatkaAI/icons/items/<ID>.png`. При наличии совместимого загрузчика mimgui она заменяет иконку категории.
- Единый журнал: все события, тайники, PayDay, продажи, скупка и доходы. История событий пишется в `PalatkaAI/logs/events.jsonl`.
- Подписка `samp.events.onServerMessage(color,text)` теперь ловит игровые уведомления; прежний обработчик чата оставлен как резерв, с защитой от одинаковых сообщений подряд.
- Запись PayDay больше не зависит от переключателя Telegram. Выплаты и явные сообщения о продаже/покупке обрабатываются по консервативным шаблонам.
- История наград (`rewards.jsonl`) сохраняется и выводится отдельно от остальных событий.

## Установка

1. Положить `palatka_ai.lua` в папку Lua-скриптов вашего MonetLoader / MoonLoader, заменив старую версию.
2. Запустить игру, открыть `/crr`; мини-журнал — `/crlog`.
3. Для реального выставления снять флажок `Проверить без выставления`. Не выставляйте без предварительной проверки цен и количеств.
4. Можно пользоваться одним `palatka_ai.lua`: картинки категорий извлекаются автоматически при доступной записи файлов.

## Ограничения и проверка

- Изображения в комплекте — стилизованные миниатюры категорий, не точные игровые картинки каждой из ~9000 позиций. Для точных изображений нужны PNG по ID.
- Нужна поддержка текстур mimgui на конкретном Android-клиенте; при отсутствии текстур отображается текстовая заглушка.
- Локально проверены сборка CP1251, компиляция texlua, эмуляция серверных PayDay/доходов/покупок/продаж, базовый торговый экран, распаковка PNG.
- **Не проверялось в реальном MonetLoader / Arizona RP**. Тексты серверных уведомлений могут отличаться; для недостающих паттернов нужны реальные строки чата.
- Информационные оценки прибыли по предметам могут не соответствовать поступлению наличных; журнал показывает это раздельно.
