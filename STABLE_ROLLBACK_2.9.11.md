# Palatka AI 2.9.11 — стабильный откат

Технический код: **2.9.5** (проверенная сборка). Номер выпуска: **2.9.11** — выше неисправной 2.9.10 для корректного автообновления.

Откуда восстановлено: commit 778915d9291cbd2b50e683cf3d5433d3c88d900c. Затронуты только номер версии, небольшая обёртка установки OTA, манифест и процесс проверки/сборки. Никаких изменений в торговых алгоритмах, журнале, автопиаре и данных пользователей нет.

Файл обновления: `updates/palatka_update.lua`. Манифест: `version.json`.

Порядок действий на Android: главное меню → Настройки → Обновления → «Проверить обновления» → установить 2.9.11 → перезапустить скрипт. Если синтаксическая ошибка сохраняется, проверить, что скачивается файл из основной ветки и не остаётся ранее испорченный `update.new.lua`.

Перед любым следующим обновлением необходимо проверять **ровно опубликованный OTA** компилятором LuaJIT, совпадение байт с манифестом и сборку полного файла. Нельзя публиковать не прошедшие проверки обновления.
