# Palatka AI v2.2.5 — диалоги, реклама лавки, адаптивные окна, учёт

**27 октября 2026.** Это самостоятельная Palatka AI. Market Helper использовался только как образец для сопоставления уже известных последовательностей игровых диалогов; никакого импорта, require, общих настроек, токенов или обязательной связи с ним нет.

## Реализовано

- Выставление **продажи**: ожидание стабилизированного содержимого диалога именно нужного предмета, а не только ID. Не отправляет цену в чужое или ещё не загрузившееся окно. Сохранены локальные стеки, снимок очереди при запуске, тестовый режим, подтверждения из чата.
- Выставление **скупки**: безопасный выбор результата поиска с номером строки, цветом и колонками, полное соответствие имени; при неоднозначности — отказ. Стабилизация диалога ввода цены. Продолжает поддерживать два формата: количество,цена и только цена.
- **Тестовый запуск** RPC/диалогов продажи и скупки в headless simulator с проверкой, что не произошёл реальный запрос выставления; отдельный сценарий чужого предмета.
- **Окна** «Разбор сделки», «Цена для пресета», «Шаблон рекламы»: можно увеличивать за нижний край. Содержимое в прокручиваемом дочернем окне, крупные кнопки листания; основной UI не теряется.
- **Авто-пиар**: один шаблон содержит 1–6 строк `/vr`, `/fam`, `/gd`, `/s`, `/ad`, рассылаемых по одной с общим интервалом минимум 180 с. Никогда не отправляет все строки за раз. В редакторе — многострочный ввод.
- Кнопка **«Вставить лавку»** добавляет `{лавка}`. Перед отправкой она превращается в кликабельный `:lavkaID:`; `{номер}` подставляет только цифры. Номер берётся из явного поля или из открытой **своей** лавки при совпадении владельца и ника; из чужой не берётся. Если источника нет, отправка не выполняется.
- Убраны жёсткие `DsPic` из подписи уведомлений и вычисления ника API.
- **Журнал**: сделки с предметами, оценёнными по справочной цене скупки, теперь помечаются как оценочные, а не доказанная прибыль. Денежный поток остаётся отдельным; в модели добавлены итоги `estimated_result` и `confirmed_result`. Наследованные обмены без признака также не считаются подтверждённой прибылью.
- Цена «Рынок / Скупка / Сегодня» сохраняет различие объявлений и фактической истории ЦР; без достоверной истории «Сегодня» не создаётся искусственно.

## Проверки (не выдавать за нативные)

- `python3 build.py`: exit 0, автономный Lua CP1251.
- `python3 tools/verify_embedded_icon_bank.py`: 8028/8028 PNG по SHA-256 и смещениям, exit 0.
- `texlua tests/test_*.lua`: 59/68 exit 0; 9 недоступных для `texlua` (восемь `bit`/FFI, один синтаксис LuaJIT `+=`). Результаты по файлам — `docs/v225_texlua_results.json`.
- `python3 run_tests.py`: exit 1 **до запуска тестов**; LuaJIT не установлен.
- `tests/test_v225_game_sim.lua`: модель последовательности API вызовов без сервера, dry-run продажа/скупка и отказ при чужом предмете.
- `tests/test_v225_promo_batch.lua`: очередь каналов, кликабельная ссылка, cooldown, запрет подстановки чужой лавки.
- `tests/test_v225_journal_provenance.lua`: граница между денежным потоком и оценочной стоимостью предметов.

**Ни реального Android/MonetLoader, ни Arizona RP в окружении не было.** Конкретные реальные диалоги могут меняться при обновлении. Срабатывание шаблона или `sampSendDialogResponse` в симуляторе НЕ доказывает успешное выставление на игровом сервере.

## Что проверить на Android (без сделок)

1. Включить ТЕСТ, просканировать инвентарь, открыть **свою** лавку, попробовать одну строку продажи. Прислать статус и ID открывшегося диалога (из `standalone.log`).
2. В ТЕСТ запустить одну строку скупки, посмотреть весь путь: меню, поиск, список результатов, цена. Проверить, что предмет совпадает, и ничего реально не выставилось.
3. Для небольшого окна «Цены → Настроить» проверить нижний край, прокрутку, стрелки и доступность нижних кнопок.
4. В шаблоне пиара вписать `'/vr Покупайте в лавке {лавка}'`, выставить свой номер и посмотреть сформированный текст через проверку/ручную отправку **только когда готов к чату**. Реальную отправку не запускать в автоматическом тесте.
5. Снять реальные dialog ID, title и очищенные строки, если торговля по-прежнему не работает. Без этих пакетов точное поведение сервера не воспроизвести.
